# Phase 0 Archive Scripts

This directory contains historical exploratory and characterization scripts from Phase 0.

> [!NOTE]
> These archived scripts represent historical exploratory workflows and are preserved strictly for provenance. Exactly 19 archived scripts in this directory contain legacy non-working absolute or relative path strings (e.g. `src/configs/gazebo_maps`). Per Zenodo release specification, archived scripts are kept unchanged as history and are not actively maintained or executed during `make all`.
